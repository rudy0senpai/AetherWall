# Screen 13 — Wallpaper Games Launcher / Details

## Layout

```
+------------------------------------------+
| Navigation | Search | [Wallpaper Games]   |
+------------------------------------------+
| Game launcher list                        |
| [card] [card] [card] [card] [card] [card] |
+------------------------------------------+
| Filter: category | input support | rating  |
+------------------------------------------+
```

## Card content

- Thumbnail (screenshot or title screen).
- Title + description + category.
- Actions: launch, details, configure, remove.

## Game details

- Thumbnail + description + input mapping + resource policy (CPU/GPU/memory
  limits).
- Controls: configure inputs, save state, pause/resume, quit.
- Resource policy displayed as badge.

## States

- Loading, empty, error, offline, launch failed, permission denied.
