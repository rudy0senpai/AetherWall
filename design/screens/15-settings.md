
## Sections

- Appearance: theme, accent color, font size.
- Interface: compact mode, keyboard shortcuts help.
- Library: import folder, default thumbnail size.
- Displays: scale factor, orientation.
- Providers: enable/disable, provider settings.
- Storage: cache size, data location.
- About: version, license, acknowledgments.

## States

- Loading, error (settings failed to load).
