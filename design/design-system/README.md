# Design System — AetherWall

This directory is the authoritative source for visual and interaction design.

## Structure

- `tokens.css` — design tokens (colors, spacing, elevation, motion).
- `typography.css` — type scale, font families, line heights.
- `spacing.css` — spacing scale.
- `README.md` — this file.

## Reference hierarchy

1. User-supplied AetherWall reference images and explicit corrections.
2. Approved design-system tokens.
3. Screen specifications in `design/screens/`.
4. Component specifications in `design/components/`.
5. Prototype implementation.

## Principles

- Dark futuristic interface.
- Black and graphite surfaces.
- Purple and magenta primary accents.
- Subtle gradients and glass effects.
- Professional desktop application aesthetics.
- Large wallpaper previews.
- Consistent spacing, typography, icons, and component states.
