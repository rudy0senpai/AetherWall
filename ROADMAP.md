# AetherWall Roadmap

## Phase 0 — Foundation (current)

- [x] Repository structure established
- [x] Phase 0 documentation integrated
- [x] Design system created
- [x] Architecture decisions recorded
- [x] Screen prototypes implemented
- [x] Security model documented
- [x] Test strategy and test catalogue defined
- [ ] Phase 0 acceptance review and sign-off

## Phase 1 — Core application (planned)

- [ ] Rust daemon and core crates
- [ ] Qt 6 / QML Studio UI
- [ ] Image/slideshow runtime
- [ ] libmpv video runtime
- [ ] Qt WebEngine web runtime
- [ ] wgpu + glTF 3D runtime
- [ ] Constrained HTML5 game runtime
- [ ] KDE Plasma 6 backend

## Phase 2 — Content and customization

- [ ] Provider adapters for anime images and videos
- [ ] Web wallpaper creator/workshop
- [ ] Slideshow editor
- [ ] 3D scene editor
- [ ] Game launcher

## Phase 3 — Distribution

- [ ] Packaging and installers
- [ ] Desktop integration (Plasma widgets)
- [ ] Documentation and user guide
- [ ] Release automation

## Out of scope (first product baseline)

- System-monitoring HUD on the desktop
- Arbitrary native executable plugins from wallpaper packages
- Built-in social network or account system
- Cloud sync as a mandatory dependency
- Guaranteed support for every Wayland compositor at launch
- DRM circumvention or scraping that violates provider terms
